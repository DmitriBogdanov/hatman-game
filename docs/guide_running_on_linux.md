# Running the game on Linux

[<- to README.md](..)

This game is perfectly compatible with [Wine](https://www.winehq.org/), which can be used to run it on most POSIX-compliant systems.

To install `Wine` with `apt` run:

```bash
sudo apt update &&
sudo apt install wine
```

To run the game, execute following command from the game directory:

```bash
wine hatman.exe
```
